⚡ PRO TIPS
═══════════════════════════════════════════════════════════════════════════════════

  1. Abre TWO terminales:
     • Terminal 1: `pnpm dev` (déjalo corriendo)
     • Terminal 2: Tus comandos (db:migrate, test, etc.)

  2. Edita código en VS Code:
     • React components → HMR automático (<500ms)
     • Endpoints Fastify → Reload automático (<1s)
     
  3. Debug con VS Code:
     • Attach debugger a puerto 9229
     • Breakpoints funcionan con hot reload

  4. Monitorea colas:
     • Abre http://localhost:3001/bull-board
     • Ver BullMQ jobs en tiempo real

  5. Explora BD:
     • `pnpm db:inspect` abre Drizzle Studio
