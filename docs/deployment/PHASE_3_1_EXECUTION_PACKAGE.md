**Task 3.2: Configure Nginx**

## 🚨 CRITICAL REMINDERS

### 🔐 SECRETS MANAGEMENT
- **NEVER commit `.env.production` to git**
- Use secure methods: `scp`, `1Password`, `LastPass`, or `nano` on server
- Verify: `git log --all -S "SECRET"` returns empty
- Set permissions: `chmod 600 .env.production`

### 🌐 DOMAIN DNS
- **Must be configured BEFORE running certbot**
- Point A record to VPS IP address
- Wait for DNS propagation (can take minutes to hours)
- Verify: `nslookup yourdomain.com` shows VPS IP

### 🔄 BACKUP VERIFICATION
- Test restore at least once
- Verify: `file /opt/atlas-logistics/backups/*.db` returns "SQLite 3.x"
- Check cron job: `crontab -l`

### 📊 MONITORING ACTIVATION
- Prometheus starts automatically with `--profile observability`
- Grafana login: admin / (password from GRAFANA_ADMIN_PASSWORD)
- Add Prometheus data source: http://prometheus:9090

## 🆘 EMERGENCY PROCEDURES

### If Something Goes Wrong

**Quick Restart Everything:**
```bash
cd /opt/atlas-logistics
docker compose down
docker compose up -d
docker compose logs -f backend
```

**Restore from Backup:**
```bash
cp /opt/atlas-logistics/backups/atlas-prod-*.db /opt/atlas-logistics/data/atlas-prod.db
docker compose restart backend
```

**Clear Docker Issues:**
```bash
docker system prune -a --volumes
docker compose build --no-cache
docker compose up -d
```

**Check System Resources:**
```bash
df -h                    # Disk space
free -h                  # Memory usage
docker stats             # Container stats
ps aux | grep docker     # Docker processes
```
